**Business problem**
A churn-reduction was launched, but leadership wants to know:
"Did the intervention actually reduce churn, or would churn have changed anyway?"
This project evaluate the causal impact of the intervention using an experimental framework. 

**Experiment design**
- Randomized Control vs Treatment
- Pre- and post-intervention periods
- User-level outcomes including churn and revenue

**Data Validation**
Before analysis:
- Verified balanced sample sizes
- Checked pre-period churn similarity
- Validated tenure and pricing balance
- Confirmed no data leakage or attrition bias
This ensured the experiment was statistically valid.

**Methodology**
- Compared churn rates across groups 
- Applied Difference-in-Difference (DiD) logic to isolate causal impact.
- Removed baseline differences and time trends
- Translated churn reductions into revenue impact

**Key Results**
- ~ 4.2 percentage point causal reduction in churn
- 26% relative churn improvement
- Estimated ~ 895 000 in retained revenue over a 6-month.

**Executive recommendation**
 - Roll out the intervention to the broader user base
 - Prioritize high-risk segments
 - Monitor post-launch churn to ensure sustained impact
